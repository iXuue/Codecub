## CodeCub Phase 2 — Context Compiler（完成）

### 实现
- 新增 `codecub/context_compiler.py`（1302 行）：ContextCompiler / WorkingState / ContextBudget / ContextItem / CompiledContext / HistoryCondenser / RepoMapSelector。
  - Pinned Context：user task/project rules/safety/runtime mode/evidence ledger/checkpoint/relevant memory（稳定 key + dedup + overflow 不静默删）。
  - Working State：Task-local、客观事件驱动、bounded（facts≤24/changed≤12/verif≤8/blockers≤6/symbols≤16/failed≤6）。
  - Recent Verbatim：budget 比例 + floor 2 组；native assistant.tool_calls+tool results 原子组（无 orphan）。
  - Compressed History：HistoryCondenser（deterministic 默认 + LLM 接口预留，失败保留 raw，绝 summary="" 删历史）；Recursive condensation。
  - Repo Map：CodeIndex 升级为 model-visible map（task lexical + touched files 排序，独立 budget）。
  - Budget：usable = window - output - tool_overhead - safety_margin；fallback 12000 + budget_source 标记。
  - Freshness：fact 带 source_hash（复用 memory.file_freshness）；stale 显示为 stale。
  - Pipeline：A dedup → B compact bulk → C structured condensation → D recursive；禁止 blind pruning。
- `codecub/runtime.py` 集成：feature flag `context_compiler`（默认 True）；working_state 每轮更新；compile_text 走 compiler（legacy）；native 请求前 compile_native（不压缩返回原引用，压缩时重组）；checkpoint 在 compression 时创建（trigger=context_reduction 兼容）；observability trace 事件 + `_add_legacy_metadata_compat` 兼容旧字段。
